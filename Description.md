# SIS 2: Test Automation with Playwright

## Target Application
- **URL**: https://practicesoftwaretesting.com/
- **Description**: An open-source e-commerce web application designed for practicing automated testing.

## List of Automated Test Cases (AT Suites)
1. **TC01: User Login** - Verifies that a registered user can successfully log into the system with valid credentials.
2. **TC02: Product Search** - Verifies that searching for a keyword (e.g., "Pliers") filters and displays relevant products.
3. **TC03: Add Product to Cart** - Verifies that a user can open a product details page and add the item to the shopping cart.
4. **TC04: Checkout Flow Navigation** - Verifies that the cart correctly reflects added items and proceeds to the checkout step.
5. **TC05: Contact Form Submission** - Verifies that the contact page allows filling out user inquiries and submitting them successfully.
